<h1 align="center">Smart Kettle API 🫖</h1>



### Локальный мост для интеграции чайника Xiaomi Kettle 2 Pro (предназначенный для китайского рынка) в умный дом Яндекса (Алису)###
---
### 🎯 Решаемая проблема
Проект решает проблему региональных ограничений:
* **Прямое управление** устройством без задержек
* **Независимость** от китайских серверов

## 🚀 Основные технические решения

*   **Асинхронная бэкенд-интеграция:** Создал асинхронный сервис для опроса умных устройств (FastAPI + asyncio). Тяжелые сетевые запросы вынесены в `asyncio.to_thread` для избежания блокировки event loop-a
*   **Предиктивный расчет:** Реализовал алгоритм расчета оставшегося времени нагрева на основе математического моделирования
*   **Собственный OAuth2 Server:** Реализовал сервер авторизации с редиректами, валидацией данных и генерацией защищенных JWT-токенов
*   **Адаптер Yandex Smart Home API:** Реализовал спецификацию Яндекса (Discovery, Query, Action) с динамической обработкой вложенных JSON-запросов
*   **Резервный канал управления:** Поднял полноценный Telegram-бот на `aiogram 3` с машиной состояний для управления чайником в случае недоступности серверов Яндекса
*   **Защита инфраструктуры и логирование:** Swagger закрыт от ботов сканеров с помощью HTTP Basic Auth. Также настроен перехват и ротация логов Uvicorn с помощью `Loguru`

## 🛠 Стек технологий
*   **Backend:** Python 3.11, FastAPI, Pydantic
*   **Telegram Bot:** Aiogram 3
*   **IoT Protocol:** python-miio
*   **Security:** PyJWT, secrets
*   **Logging:** Loguru

## 🚧 Roadmap и технический долг (Work in Progress)

В ближайших планах по развитию:

- [ ] **Миграция OAuth2:** В текущей версии для упрощения архитектуры используется статический `authorization_code`. Планируется миграция на динамическую генерацию кодов с хранением сессий в **Redis**.
- [ ] **Сбор метрик и дашборды:** Подключение **InfluxDB** для хранения данных о температуре воды и вывод красивых графиков остывания/нагрева в **Grafana**.
- [ ] **Docker:** Упаковка всего в Docker для поднятия всего (API, Bot, Redis, Influx) одной командой.
